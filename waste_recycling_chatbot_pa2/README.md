# Swiss Waste Recycling Agent

Bachelor Thesis – ZHAW Wädenswil  
Author: Lejla Beganovic  
Supervisor: Martin Schüle, Stefan Glüge

## About

An agentic AI system for Swiss waste recycling guidance built with LangGraph and GPT-4o.

## Features

- Image-based waste classification (MobileNetV3, 16 Swiss categories, 95% accuracy)
- Swiss Recycle compliant disposal guidance
- Location-aware collection point lookup via OpenStreetMap
- Bilingual support (EN/DE)
- Session memory across conversation turns
- Responsive design for mobile and desktop
